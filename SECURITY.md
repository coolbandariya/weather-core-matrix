# Security Policy

## Reporting a vulnerability

Please do not disclose vulnerabilities in public issues. Use GitHub's private vulnerability reporting feature (Security tab) where available. Include the affected commit, reproduction steps, impact, and mitigation ideas. Never include credentials, personal data, or production secrets.

## Scope

The default branch is the supported development line. This project may be a prototype; review its deployment, dependencies, data handling, and access controls before using it with sensitive or production data.
